# Amendment Template

## Purpose

This template helps learners revise systems in a visible, organized way.

## When to Use It

- Week 14
- Week 18
- Any time a rule, agreement, or Charter needs a patch after stress-testing or a real dispute

## Student Directions

Write the exact change, explain what problem triggered it, and record how it was approved.

## Facilitator Notes

- Do not rush amendments during a heated conflict.
- Ask whether the amendment fixes a real gap or just reacts to one person's frustration.
- Remind learners that amendment is a design tool, not a punishment tool.

## Template

```text
AMENDMENT TITLE:

Current document and version:
Date proposed:
Proposed by:

WHAT PROBLEM SHOWED UP?

WHAT PART OF THE DOCUMENT IS CHANGING?

OLD TEXT:

NEW TEXT:

WHY THIS PATCH IS NEEDED:

WHAT SCENARIO OR CASE TRIGGERED IT?

WHO DISCUSSED IT?

HOW IT WAS APPROVED:

DATE RATIFIED:

NEXT REVIEW DATE:
```

## Younger Learner Adaptation

- Use "Old rule / New rule / Why" instead of full sections.
- Let the learner explain the patch out loud first.

## Older Learner Extension

- Add a note on whether the amendment changes a rule, a definition, a right, a procedure, or a remedy.
- Add version numbering and a short amendment history.
