# Precedent Ruling Log

## Purpose

This log helps learners feel how early decisions shape later ones.

## When to Use It

- Week 10
- Any rule-interpretation activity where earlier rulings are meant to constrain later ones

## Student Directions

Fill in one row for each case. Keep referring back to earlier cases as you go.

## Facilitator Notes

- Run cases in order.
- Ask learners to name the prior case that controls the new one.
- Use the "distinguish" and "overturn" columns only when the learner is ready for them.

## Younger Learner Adaptation

- Use four cases instead of eight.
- Replace the last three columns with one prompt: "How did an earlier case affect this one?"

## Older Learner Extension

- Add a final paragraph: "Which ruling would I change now, and why?"
- Add jurisdiction notes if comparing different legal systems or school systems.
